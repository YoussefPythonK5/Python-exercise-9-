# Average Calculator

This program solves the problem of manually calculating mathematical averages by automatically taking a list of numbers from the user and finding their mean value.

## How It Works
1. It takes numbers from the user separated by spaces.
2. It converts the input into a list of integers.
3. It calculates and prints the final average.

## How to Run
You can run this script on any standard Python compiler or IDE (like VS Code, PyCharm, or any online Python compiler). Simply execute the file, enter your numbers separated by spaces, and press Enter.

## Tools Used
* **Language:** Python 3
* **Concepts:** Input splitting, loops (`for`), list manipulation (`append`), and built-in math functions (`sum`, `len`).
